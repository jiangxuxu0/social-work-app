# 春晖护老管理系统

## 项目简介
面向养老院/康复中心的社会工作管理应用，帮助社工高效管理老人档案、进行ADL评估、记录服务历程。

## 技术栈
- Next.js 14 + React 18
- shadcn/ui 组件库
- Supabase（数据库 + 认证）
- Tailwind CSS 3

## 核心功能
1. **老人档案管理** - 管理老人基本信息（姓名、年龄、入住日期、健康状况、负责社工）
2. **ADL评估** - 10项日常生活能力评估，自动计分和等级评定
3. **服务记录时间轴** - 记录服务内容和下次跟进提醒

## 运行方式
```bash
# 安装依赖
npm install

# 配置环境变量
# 复制 .env.example 为 .env 并配置 Supabase 信息

# 启动开发服务器
npm run dev
```
